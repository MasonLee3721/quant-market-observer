# ADR-0001：資料供應策略不綁定 FinLab

- 狀態：Accepted
- 日期：2026-09-27

## 背景

專案需要最近兩年的台股價量、法人及融資融券資料，也希望公式與資料處理透明。FinLab 提供便利的 Point-in-time 資料與回測介面，但免費方案依官方 FAQ 只提供至 2020 年底，不能完成最近兩年 M0 驗證。

## 決定

- TWSE／TPEx 作為最新資料及抽樣核對的權威來源。
- FinMind 作為 M0 與 MVP 的歷史整合來源。
- 以 provider adapter 隔離外部來源，FinLab 日後可以選配接入。
- 自建核心指標與回測規則，不讓任何單一供應商成為必要依賴。

## 後果

優點：降低平台綁定、可公開方法論、可替換來源。缺點：專案需自行負責 schema 對齊、除權息、歷史股票池、資料品質與回測成交規則。

## 重新評估條件

若 FinMind 額度、穩定性或授權無法支援個人研究，或自行維護成本顯著超過 FinLab 訂閱成本，重新比較混合方案。
