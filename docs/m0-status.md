## Spike 摘要

以 `docs/m0-spike-result.md` 的最後一次執行為準：

- 股票覆蓋：三個 dataset 均為 50/50。
- 代表主題：23。
- 價量資料：約 2.4 萬筆。
- 主鍵重複：0。
- 無效價格：0。
- 無成交列：保留資料列、價格轉為 null，並加上 `no_trade` 旗標。
- 價量、法人、融資同日 join 比率：高於 99%。
- 官方抽樣對帳：OHLC、成交股數、成交金額完全相等。

## M0 發現

1. FinLab 很便利，但不是 MVP 必要依賴；免費資料時效不足以驗證最近兩年。
2. FinMind 足以支撐個人研究的歷史 spike，但正式每日資料仍應由官方來源核對。
3. 停牌／無成交在來源中可能以價格 0 表示，標準化時必須轉為缺值並保留語意旗標。
4. 法人資料筆數可能略少於價量資料；融資資料也不應被假設每日必然存在。
5. 未還原價格不能直接用於跨除權息的正式報酬研究。
