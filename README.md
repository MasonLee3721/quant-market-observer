# Quant Market Observer

台股量化市場觀察與策略驗證系統。

本專案將每日市場資料轉換為可解釋的市場狀態、族群輪動與個股排名，並以歷史回測檢驗每一項判讀。最終產物是一份可離線開啟、具資料溯源能力的單一 HTML 報告。

> 本專案僅供個人研究與投資學習，不構成投資建議；第一階段不包含自動下單。

## 專案狀態

目前處於規劃階段。完整範圍、架構、里程碑與驗收標準請見 [PROJECT_PLAN.md](PROJECT_PLAN.md)。

## 核心輸出

- 市場風險狀態：積極／中性／保守
- 族群輪動：主升／剛啟動／高檔鈍化／槓桿推動／資金撤退
- 個股排名：領頭／剛啟動／觀察／排除
- 訊號歷史驗證：超額報酬、勝率、回撤、換手率與交易成本
- 每日單一 HTML 研究報告

## 原則

1. 先定義公式，再寫敘事。
2. 所有結論都能追溯至資料、日期與版本。
3. 嚴格防範未來函數、倖存者偏誤與過度擬合。
4. 先完成可解釋的規則模型，再評估機器學習。
5. 報告呈現觀察證據，不提供保證獲利或明牌。
